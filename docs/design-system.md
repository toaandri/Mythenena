# Mythenena — jardin calme

Shared web/mobile direction: ivory #F8F6F0, forest #183E36, primary #276653,
sage #E6EDE5, apricot #EEBC96. Body text uses high-contrast forest/gray;
white is reserved for cards and primary-button labels. Spacing follows 8px
increments, cards have 24px corners, interactive targets are at least 44px.
Display headings use editorial serif styling, body text stays system sans.
Keep loading, error, focus, disabled and selected states distinguishable.
Support reduced motion and wrapping text; avoid fixed text heights.
